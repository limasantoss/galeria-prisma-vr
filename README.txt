Galeria Prisma VR

Descricao curta
- Ambiente educativo em Unity com tema Web3 para atividade introdutoria de XR/VR.

Arquivos principais
- Cena principal: Assets/ProjetoVR/Scenes/GaleriaPrisma_Main.unity
- README interno: Assets/ProjetoVR/Docs/README.txt
- Relatorio tecnico: Assets/ProjetoVR/Docs/Relatorio_ProjetoVR.txt

Como abrir no Unity
- Abra o projeto no Unity 6000.3.13f1.
- Abra a cena Assets/ProjetoVR/Scenes/GaleriaPrisma_Main.unity.

Controles no PC/Editor
- W/A/S/D para mover
- Mouse para olhar
- Left Shift para correr
- E para interagir com os prismas

Observacao
- Este README.txt na raiz complementa a documentacao interna e o README.md do repositorio.
